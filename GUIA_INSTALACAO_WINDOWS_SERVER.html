🐕 Scooby OS - Guia de Instalação

Manual Oficial de Deploy em Windows Server / Computador Central
Versão Servidor 24/7

🌐 1. Arquitetura da Rede Local

O Scooby OS funciona centralizado em um único computador/servidor na oficina, atendendo simultaneamente todas as estações de trabalho via rede local (Cabo ou Wi-Fi):

📋 2. Pré-Requisitos no Servidor (Instalar 1 única vez)

  1. Node.js (v20 ou v22 LTS): Baixe e instale em https://nodejs.org (marque a opção padrão de adicionar ao PATH).
  2. Docker Desktop for Windows: Baixe e instale em https://docker.com (necessário para o PostgreSQL 16 e Redis 7).
  3. Git for Windows (Opcional): Baixe em https://git-scm.com (facilita atualizações automáticas).

🚀 3. Passo a Passo de Instalação

1Copiar os Arquivos do Pen Drive para o Servidor

Conecte o Pen Drive no Windows Server e copie a pasta SCOOBY_PENDRIVE para a unidade C:\ do computador, renomeando para C:\Scooby.

2Executar o Instalador Automático

Dentro da pasta C:\Scooby, clique com o botão direito no arquivo:

INSTALAR_WINDOWS_SERVER.bat ➔ "Executar como Administrador"

O script executará automaticamente todas as tarefas:

  • Inicia os contêineres do PostgreSQL 16 e Redis 7 via Docker.
  • Instala todas as dependências e compila o Frontend de alta performance.
  • Cria a regra no Firewall do Windows liberando a Porta 3001 para a rede local.
  • Configura a tarefa de Backup Automático Diário para as 19:00h.
  • Exibe na tela o IP Local da máquina para acesso dos outros computadores.

3Restaurar os Dados do Banco Existente (Clientes, OSs e Estoque)

Após a conclusão do instalador, execute com 2 cliques o arquivo:

RESTAURAR_BACKUP_BANCO.bat

O script listará os backups disponíveis na pasta backups/. Digite o número correspondente ao arquivo .sql mais recente e confirme digitando SIM. Todos os seus dados serão carregados instantaneamente!

💻 4. Como Conectar os Outros Computadores da Oficina

Em qualquer computador do Balcão, Bancada ou Gerência conectado no Wi-Fi ou cabo da loja:

  1. Abra o navegador de internet (Google Chrome, Edge).
  2. Digite o endereço com o IP do servidor (exemplo):
    http://192.168.100.73:3001
  3. Criar Atalho na Área de Trabalho: No Chrome ou Edge, clique nos 3 pontinhos do canto superior ➔ "Mais Ferramentas" / "Aplicativos" ➔ "Instalar este site como aplicativo" ou "Criar Atalho...".

💾 5. Rotina de Backups e Segurança de Dados

  • Backup Automático: Configurado para rodar todos os dias às 19:00h de forma silenciosa, salvando cópias .sql na pasta C:\Scooby\backups e mantendo os últimos 30 dias.
  • Backup Manual: Dê 2 cliques em GERAR_BACKUP_BANCO.bat a qualquer momento.
  • Recomendação de Segurança: Uma vez por semana, copie os arquivos da pasta backups/ para um Pen Drive externo ou Google Drive.

🔄 6. Como Atualizar o Sistema Sem Perder Nenhum Dado

Sempre que novas melhorias forem desenvolvidas:

  1. Dê 2 cliques no arquivo ATUALIZAR_SISTEMA_SEM_PERDER_DADOS.bat.
  2. O script gera um backup preventivo do banco, baixa as atualizações e recompila o sistema mantendo 100% das suas OSs, clientes e cadastros intactos.

📁 7. Resumo dos Arquivos do Servidor

❓ 8. Dúvidas Frequentes

P: O computador do balcão não consegue abrir o link do servidor.
R: Verifique se ambos os computadores estão conectados na mesma rede Wi-Fi/cabo e se a regra da porta 3001 foi criada no Firewall do Windows Server executando o instalador como Administrador.


P: E se faltar luz ou o servidor reiniciar?
R: O Docker inicia o banco de dados e cache automaticamente com o Windows. Para iniciar o Scooby OS, basta dar 2 cliques em INSTALAR_WINDOWS_SERVER.bat (ou deixar o serviço do PM2 configurado para início com o Windows).
